# FAANG-уровень персональный агент

Улучшенный MVP агента, который умеет:
- автоматически определять тип задачи (`auto`);
- отвечать на email в профессиональном стиле;
- предлагать кодовые решения;
- делать быстрый архитектурный анализ проекта.

## Самый удобный запуск (локально)

```bash
./run_agent.sh
```

Дальше просто вводишь задачу в терминале.

## Запуск через Makefile

```bash
make run           # интерактив, mode=auto
make run-email     # интерактив, mode=email
make run-code      # интерактив, mode=code
make run-analysis  # интерактив, mode=analysis
make test          # тесты
```

## Запуск одной командой

```bash
python3 faang_agent.py --task "Ответь клиенту, что баг принят в работу"
python3 faang_agent.py --task "Напиши функцию Python для кэширования с TTL"
python3 faang_agent.py --mode analysis --task "Оцени архитектуру этого проекта"
```

## Режимы

- `auto` (по умолчанию): агент сам выбирает между `email` / `code` / `analysis`.
- `email`: генерация делового ответа.
- `code`: код + риски + следующие шаги.
- `analysis`: обзор проекта с базовой статистикой файлов.

## Что стало лучше

1. Добавлен авто-роутинг задач по ключевым словам.
2. В `code`-режиме пример кэша улучшен: `maxsize`, валидация параметров, потокобезопасность.
3. В `analysis`-режиме сканируется весь репозиторий (без `.git`) и считаются top расширения файлов.
4. Добавлен удобный интерактивный запуск без обязательного `--task`.
